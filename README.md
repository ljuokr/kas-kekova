# Kaş–Kekova Paddelkarte

Offline-Karte der Seekajak-Rundtour Kaş–Kekova (Oktober 2026): Route, Schutzzone,
Übernachtungsspots mit Google-Maps- und Satellit-Links. Single-File-HTML, Basiskarte
(GSHHG-Küstenlinie) eingebettet, funktioniert nach dem ersten Laden ohne Netz.

- `index.html` – Karte
- `Kas-Kekova_Woche.gpx` – Track und Wegpunkte für Organic Maps / GPS
